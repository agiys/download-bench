# download-bench

Консольный скрипт на Node.js 18+ (без зависимостей): делает 10 последовательных запросов к адресу, полностью скачивает каждый ответ и считает статистику.

## Запуск

```
node bench.js https://example.com/big-image.jpg
```

Необязательные параметры:

- `-n`, `--requests` — число запросов (по умолчанию 10)
- `-t`, `--timeout` — таймаут запроса в секундах (по умолчанию 30)

## Вывод

Для каждого запроса — размер и время, в конце:

- среднее время запроса, секунды;
- общий объём скачанных данных, МБ (1 МБ = 1024 × 1024 байт) и байты;
- скорость скачивания: общий объём / суммарное время запросов, в МБ/с (дополнительно в Мбит/с).

## Ошибки

При ошибке сети или неверном адресе скрипт печатает причину в stderr и завершается с кодом 1.
